# 옷은 달력 보고 살까, 날씨 느끼고 살까?

**반팔·겉옷·패딩 검색량과 서울 기온 10년치를 비교해서, 사람들이 옷을 찾는 시기가 "달력"을 따르는지 "날씨"를 따르는지 확인한 데이터 분석 프로젝트입니다.**

## 한 줄 결론

> **패딩만 날씨를 따라갑니다.** 기온이 약 10℃ 아래로 내려가면 며칠 뒤 검색이 가장 많아집니다. 반팔과 겉옷은 날씨를 따라간다고 말할 근거가 부족합니다.
>
> **그래서 올해(2026) 패딩은?** 올해는 10월 중순이 과거 9년보다 따뜻해서, 패딩이 가장 붐비는 때가 평년(11월 17일)보다 늦은 **11월 24일 전후**로 예상됩니다. (대략 11월 15일 ~ 12월 3일, 신뢰는 낮은 편)

![결과 그래프](images/04_weather_vs_calendar.png)

*그래프 읽는 법: 막대가 낮을수록 "검색이 가장 많은 날"을 더 정확히 맞힌 것입니다. 회색은 "매년 같은 날짜"로 예측, 색깔 막대는 "그해 기온"으로 예측한 결과예요. 패딩만 색깔 막대가 확실히 낮습니다.*

---

## 그래서 우리 소비에는? (올해 패딩 타이밍)

![올해 패딩 예상](images/09_padding_2026_forecast.png)

*그래프 읽는 법: 위 9줄은 과거 기록(빈 동그라미 = 기온이 10℃ 아래로 내려간 날, 파란 동그라미 = 패딩 검색이 가장 많았던 날)이고, 아래 줄이 올해 예상입니다. 연한 띠는 예상이 빗나갈 수 있는 폭이에요.*

- **언제 몰리나?** 패딩 검색은 기온이 10℃ 아래로 내려가기 **약 3주 전부터** 오르기 시작해서, 내려간 날 전후로 가장 붐빕니다.
- **올해는?** 요즘 서울 기온이 과거 9년 같은 날보다 높아서(최근 7일 평균 19.3℃ vs 평균 15.7℃) 10℃ 도달이 평년(11월 8일)보다 늦은 11월 중순으로 예상됩니다.
- **그럼 언제 사면 좋을까?** 가장 붐비는 시기를 피해 11월 초·중순 이전에 비교해 보는 게 선택지입니다. 다만 **가격은 확인하지 못해서** "더 싸다"는 보장은 없습니다.
- **맞는지 확인하려면?** 12월에 데이터를 다시 받아 `python analysis.py`를 실행하면 예상과 실제를 비교할 수 있습니다.

## 이 프로젝트에서 한 일

| 단계 | 한 일 |
|---|---|
| 1. 궁금한 것 정하기 | "겉옷 살 때를 달력이 알려줄까, 날씨가 알려줄까?"를 5개 질문으로 쪼갬 |
| 2. 데이터 모으기 | 네이버 데이터랩에서 옷 검색량, 기상청에서 서울 일평균기온을 직접 내려받음 (10년치, 매일) |
| 3. 데이터 다듬기 | 비어 있는 값 확인, 하루만 튀는 값 6개 보정 |
| 4. 분석하기 | 해마다 검색이 가장 많았던 날을 찾고, 그날의 기온과 비교 |
| 5. 달력 vs 날씨 대결 | "매년 같은 날짜"와 "그해 기온" 중 어느 쪽이 그 날짜를 더 잘 맞히는지 비교 |
| 6. 결과가 우연이 아닌지 검증 | 유리한 기준만 골라 쓴 건 아닌지 공정하게 다시 검증 (이 과정에서 처음 결론 하나를 뒤집음) |
| 7. 올해에 적용해 보기 | 패딩 결과로 올해 패딩이 붐빌 시기를 예상 (그래프 8·9) |
| 8. 그래프와 리포트 작성 | 그래프 9개 + 상세 리포트 |

## 질문 5개와 답

| 질문 | 답 |
|---|---|
| 언제 가장 많이 찾을까? | 반팔 **5월 초**, 겉옷 **3월 초와 10월 중순**, 패딩 **11월 중순** |
| 그때 기온은? | 반팔 약 20℃, 겉옷 봄 약 8℃ / 가을 약 13℃, 패딩 약 4℃ |
| 날씨가 달력보다 잘 맞히나? | **패딩만 그렇다.** 예측이 평균 11.8일 빗나가던 것이 7.4일로 줄어듦. 우연일 가능성은 0.2% |
| 날씨가 바뀐 뒤에 사나, 미리 사나? | 패딩은 추워진 **뒤**에 찾음. 다만 "며칠 뒤"인지는 분석 설정에 따라 1~9일로 달라짐 |
| 겉옷 찾는 기간은 변했나? | 겉옷을 안 찾는 기간이 해마다 약 3일씩 짧아졌지만, 기온 변화로는 설명되지 않음 |
| (활용) 올해 패딩은 언제 붐빌까? | 11월 24일 전후 예상 (평년보다 약 일주일 늦음, 범위 11월 15일~12월 3일) |

## 알아둘 점

- 처음에는 "봄 겉옷이 날씨와 가장 잘 맞는다"고 나왔지만, 공정하게 다시 검증하니 사라졌습니다. 이 과정은 리포트에 그대로 적었습니다.
- 서울 한 곳, 연도 9~10개의 작은 데이터라 **"그럴 가능성이 있다"** 수준의 결과입니다. 검색은 실제 구매와 다릅니다.

## 실행 방법

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python analysis.py
```

Python 3.12, Mac에서 확인했습니다. 그래프의 한글이 네모로 보이면 `pip install koreanize-matplotlib`을 한 번 실행하세요.

## 사용한 기법

이동평균, 월별 집계, 상관분석, 한 해씩 빼고 예측하기(교차검증), 순열 검정, 민감도 분석, 변화율·추세, 조건부 예측(올해 시나리오)
