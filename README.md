# 환절기 옷, 수요는 언제 생길까? 날짜일까, 기온일까?

**"사람들은 계절이 바뀔 때 언제 옷을 살까?"에서 시작한 데이터 분석 프로젝트입니다.** 옷을 파는 쪽이라면 수요가 생기기 전에 환절기 옷을 출시하거나 판매를 시작하는 편이 맞을 것이라고 보고, 그 수요 시기를 반팔·겉옷·패딩 검색량과 서울 기온 10년치로 확인했습니다.

**질문은 이렇게 이어집니다.**

1. 수요가 생기는 때는 언제인가?
2. 그 시기는 날짜(달력)로 정해지는가, 기온(날씨)을 따라 움직이는가?
3. 기온을 따른다면, 기온이 예전과 달라진 요즘은 그 시기가 언제 오는가?

## 처음 질문에 대한 답

1. **수요는 언제 생기나?** 반팔은 5월 초, 겉옷은 3월 초와 10월 중순, 패딩은 11월 중순에 검색이 가장 많습니다.
2. **날짜로 정해지나, 기온을 따르나?** **패딩만 기온을 따릅니다.** 기온이 약 10℃ 아래로 내려가기 약 3주 전부터 검색이 오르기 시작해 내려간 날 전후에 가장 많아집니다. 반팔과 겉옷은 날씨가 달력보다 낫다고 말할 근거가 부족합니다.
3. **기온이 달라진 요즘은 언제 오나?** 올해는 10월 중순이 과거 9년보다 따뜻해서, 패딩이 가장 붐비는 때가 평년(11월 17일)보다 늦은 **11월 24일 전후**(11월 15일~12월 3일)로 예상됩니다. 신뢰는 낮은 편입니다.

**판매자에게는:** 패딩은 달력 고정 일정보다 가을 기온 흐름에 맞춰 준비 시점을 잡는 쪽이 데이터와 맞습니다. 반팔과 겉옷은 입증된 날씨 신호가 없어 달력 일정을 기본으로 두고 기온 기준은 실험으로 검증하는 순서가 안전합니다. 검색 관심을 근거로 한 해석이며 매출·재고·가격은 다루지 않았습니다.

*그래프 읽는 법: 막대가 낮을수록 "검색이 가장 많은 날"을 더 정확히 맞힌 것입니다. 회색은 "매년 같은 날짜"로 예측, 색깔 막대는 "그해 기온"으로 예측한 결과예요. 패딩만 색깔 막대가 확실히 낮습니다.*

## 요즘은 언제 오나? (올해 패딩 타이밍)

![올해 패딩 예상](images/09_padding_2026_forecast.png)

*그래프 읽는 법: 위 9줄은 과거 기록(빈 동그라미 = 기온이 10℃ 아래로 내려간 날, 파란 동그라미 = 패딩 검색이 가장 많았던 날)이고, 아래 줄이 올해 예상입니다. 연한 띠는 예상이 빗나갈 수 있는 폭이에요.*

- **언제 몰리나?** 패딩 검색은 기온이 10℃ 아래로 내려가기 **약 3주 전부터** 오르기 시작해서, 내려간 날 전후로 가장 붐빕니다.
- **올해는?** 요즘 서울 기온이 과거 9년 같은 날보다 높아서(최근 7일 평균 19.3℃ vs 평균 15.7℃) 10℃ 도달이 평년(11월 8일)보다 늦은 11월 중순으로 예상됩니다.
- **판매자라면?** 10℃ 도달 예상일(11월 16일 전후)보다 약 3주 앞선 10월 말쯤부터 수요 신호가 오를 것으로 추정됩니다. 다만 이것은 검색 관심을 근거로 한 해석이고, 매출·재고·가격은 다루지 않았습니다.
- **소비자라면?** 가장 붐비는 시기를 피해 11월 초·중순 이전에 비교해 보는 게 선택지입니다. **가격은 확인하지 못해서** "더 싸다"는 보장은 없습니다.
- **맞는지 확인하려면?** 12월에 데이터를 다시 받아 `python analysis.py`를 실행하면 예상과 실제를 비교할 수 있습니다.

## 질문과 답

| 질문 | 답 |
|---|---|
| 언제 가장 많이 찾을까? | 반팔 **5월 초**, 겉옷 **3월 초와 10월 중순**, 패딩 **11월 중순** |
| 그때 기온은? | 반팔 약 20℃, 겉옷 봄 약 8℃ / 가을 약 13℃, 패딩 약 4℃ |
| 날씨가 달력보다 잘 맞히나? | **패딩만 그렇다.** 예측이 평균 11.8일 빗나가던 것이 7.4일로 줄어듦. 우연일 가능성은 0.2% |
| 날씨가 바뀐 뒤에 사나, 미리 사나? | 패딩은 추워진 **뒤**에 찾음. 다만 "며칠 뒤"인지는 분석 설정에 따라 1~9일로 달라짐 |
| 겉옷 찾는 기간은 변했나? | 겉옷을 안 찾는 기간이 해마다 약 3일씩 짧아졌지만, 기온 변화로는 설명되지 않음 |
| 요즘 기온으로 보면 올해 패딩은 언제 붐빌까? | 11월 24일 전후 예상 (평년보다 약 일주일 늦음, 범위 11월 15일~12월 3일) |

## 알아둘 점

- 겉옷 봄은 기준을 정답을 보고 고르면 날씨와 잘 맞아 보이지만, 공정하게 고르면 그 관계가 사라집니다. 그래서 날씨를 따른다고 말하지 않았습니다(리포트 5장 그래프 4).
- 판매자에게 주는 의미는 검색 관심을 근거로 한 해석입니다. 매출·재고·가격은 보지 않았습니다.
- 서울 한 곳, 연도 9~10개의 작은 데이터라 **"그럴 가능성이 있다"** 수준의 결과입니다. 검색은 실제 구매와 다릅니다.

## 실행 방법

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python analysis.py
```

Python 3.12, Mac에서 확인했습니다. 그래프의 한글이 네모로 보이면 `pip install koreanize-matplotlib`을 한 번 실행하세요.
