# 사람들은 달력을 보고 옷을 살까, 바뀐 날씨를 느끼고 살까?

옷 검색량(반팔·겉옷·패딩)과 서울 기온을 같이 놓고, 소비 시기가 기온을 따라가는지 달력을 따라가는지 살펴본 시계열 분석이에요.
결과와 해석은 **[REPORT.md](REPORT.md)** 에 있어요.

## 폴더 구성

```
analysis.py        분석 코드 (실행하면 images/, outputs/ 를 다시 만들어요)
requirements.txt   필요한 라이브러리
REPORT.md          분석 리포트 (질문, 결과, 인사이트, 한계, AI 사용 로그)
data/              원본 데이터 2개
images/            그래프 7개
outputs/           표(csv)와 summary.txt (콘솔 출력 전체)
```

## 실행 방법 (Mac)

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python analysis.py
```

Python 3.12에서 확인했어요. 실행하면 `images/`에 그래프 7개, `outputs/`에 표와 `summary.txt`가 만들어져요.

그래프의 한글이 네모(□)로 보이면 `pip install koreanize-matplotlib` 을 한 번 실행한 뒤 다시 돌려 주세요.
(Mac은 보통 AppleGothic을 자동으로 찾아서 써요.)
